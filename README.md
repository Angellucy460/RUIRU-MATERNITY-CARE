### PROJECT TITLE: RIURU MATERNITY CARE WEBSITE
### 1. Introduction

The RIURU MATERNITY CARE website is a web application developed to provide information about maternity healthcare services, clinic activities, operating hours, and contact information.

The website was developed using HTML, CSS, and JavaScript. For Practical Assessment 3, jQuery was integrated into the existing application to improve interactivity and user experience.

### 2. Demonstration of the Completed Application

The completed RIURU MATERNITY CARE website was demonstrated using a web browser. The demonstration involved showing the main sections of the website, its major functionality, and its interactive features.

### 3. Demonstration of Major Functionality

The following major functionalities were demonstrated:

- **Home Section:** Displays the welcome message and introduction to RIURU MATERNITY CARE.
- **About Section:** Provides information about the clinic, its healthcare professionals, and operating hours.
- **Services Section:** Displays maternity healthcare services, including prenatal care, labor and delivery support, postnatal care, and reproductive health services.
- **Activities Section:** Displays community health education programmes, health camps, maternal support groups, and collaborations with local organizations.
- **Contact Section:** Displays clinic contact information and provides a contact form for visitors to prepare enquiries.
- **Navigation:** Enables users to move between the different sections of the website.

### 4. Demonstration of User Interaction Features

**a) Service Search Functionality**

The service search feature allows visitors to search for specific maternity services. When a user enters a search term, relevant service cards are displayed while unrelated services are hidden. The Clear Search button restores all service cards.

**b) Reading Mode**

The reading mode feature improves readability by increasing text size and line spacing. Users can activate or deactivate reading mode using the reading mode button.

**c) Contact Form Validation**

The contact form allows visitors to enter their name, email address, and message. The form validates required fields before preparing an enquiry in the user's email application.

**d) Smooth Navigation**

The navigation links allow users to move smoothly between the Home, About, Services, Activities, and Contact sections of the website.

### 5. Explanation of Application Operation

The application operates through the integration of three main technologies:

- **HTML:** Provides the structure and content of the website.
- **CSS:** Controls the layout, colors, typography, responsiveness, and visual presentation.
- **jQuery:** Handles interactive functionality, including service searching, reading mode, contact form processing, and smooth navigation.

The jQuery library was integrated into the HTML document using a CDN link. The JavaScript file uses jQuery to select HTML elements, respond to user events, and manipulate the presentation and behavior of the website.

### 6. Verification of Application Functionality

The application was checked using a web browser to confirm that its main sections and interactive features operate as intended.

The following areas were verified:

- Website sections display correctly.
- Navigation links lead to the appropriate sections.
- Service search filters the service cards.
- Clear Search restores the service cards.
- Reading Mode changes the text presentation.
- Contact form validation works.
- The contact form prepares an email enquiry.
- The website maintains a consistent presentation across its sections.

The application combines HTML, CSS, and jQuery to provide an informative, interactive, and user-friendly maternity care website. The demonstration showed the major website sections, interactive features, navigation, and organized project files.
